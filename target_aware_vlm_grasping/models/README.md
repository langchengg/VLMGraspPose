# Local Models

This directory is for local model weights and checkpoints used by optional components.

Expected local layout:

```text
models/
├── vlm/
│   ├── florence2/
│   ├── florence2-large-ft/
│   └── sam/
└── reranker/
    └── mlp/
```

The model contents are ignored by Git because they are large. Keep only this README and optional `.gitkeep` placeholders under version control.
